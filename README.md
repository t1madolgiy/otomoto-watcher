# Otomoto Watcher

Бот, который следит за новыми объявлениями на [Otomoto.pl](https://www.otomoto.pl) и присылает их тебе в Telegram. Работает бесплатно на GitHub Actions — твой компьютер не нужен.

## Как это работает

1. GitHub Actions запускает скрипт каждые 15 минут.
2. Скрипт открывает указанные URL поиска на Otomoto.
3. Находит новые объявления (которых не было в прошлый раз).
4. Отправляет каждое тебе в Telegram.
5. Сохраняет ID отправленных объявлений в файл `state.json` прямо в репозитории — поэтому одно и то же объявление не присылается дважды.

## Что понадобится

- Аккаунт на GitHub (бесплатный)
- Telegram (для бота и для получения сообщений)
- 10 минут на настройку

## Шаг 1. Создать Telegram-бота

1. Открой в Telegram чат с [@BotFather](https://t.me/BotFather).
2. Отправь команду `/newbot`.
3. Придумай имя бота (например, "Otomoto Watcher").
4. Придумай username — он должен заканчиваться на `bot` (например, `my_otomoto_watcher_bot`).
5. BotFather пришлёт тебе **токен** — длинная строка вида `123456:ABC-DEF1234...`. Сохрани его.

## Шаг 2. Узнать свой Telegram chat_id

1. Найди бота, которого только что создал, и нажми `/start` или просто напиши ему любое сообщение.
2. Открой в браузере ссылку (вставь свой токен):

   ```
   https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates
   ```

3. Найди в ответе значение `"chat":{"id": 123456789, ...}` — это твой **chat_id**.

   > Если в ответе пусто (`"result":[]`), напиши боту ещё одно сообщение и обнови страницу.

## Шаг 3. Получить URL поиска с Otomoto

1. Открой [otomoto.pl](https://www.otomoto.pl).
2. Настрой фильтры: марка, модель, год, цена, город — что угодно.
3. Скопируй URL из адресной строки. Например:

   ```
   https://www.otomoto.pl/osobowe/bmw/od-2018?search%5Bfilter_float_price%3Ato%5D=80000
   ```

> Можно настроить **несколько URL** — каждый со своими фильтрами.

## Шаг 4. Залить проект на GitHub

1. На [github.com](https://github.com/new) создай **приватный** репозиторий (например, `otomoto-watcher`).
2. В терминале в папке проекта выполни:

   ```bash
   git add .
   git commit -m "initial commit"
   git branch -M main
   git remote add origin https://github.com/<твой-логин>/otomoto-watcher.git
   git push -u origin main
   ```

## Шаг 5. Добавить секреты и переменные в репозиторий

В репозитории на GitHub:

**Settings → Secrets and variables → Actions**

В разделе **Secrets** (вкладка "Secrets") нажми **New repository secret** и добавь два секрета:

| Имя секрета            | Значение                          |
| ---------------------- | --------------------------------- |
| `TELEGRAM_BOT_TOKEN`   | токен из BotFather                |
| `TELEGRAM_CHAT_ID`     | твой chat_id (число)              |

В разделе **Variables** (вкладка "Variables") нажми **New repository variable** и добавь:

| Имя переменной          | Значение                                                                     |
| ----------------------- | ---------------------------------------------------------------------------- |
| `OTOMOTO_SEARCH_URLS`   | URL поиска с Otomoto. Несколько URL — каждый с новой строки или через `;`    |
| `MAX_AGE_HOURS`         | (опционально) сколько часов считать объявление "свежим", по умолчанию `24`   |

## Шаг 6. Первый запуск — "обучение" (важно!)

При первом запуске бот может прислать сразу 30+ существующих объявлений — это спам. Чтобы этого избежать, сделай "холостой" прогон, который просто запомнит все текущие объявления как "уже виденные":

1. В репозитории на GitHub открой вкладку **Actions**.
2. Слева выбери **Otomoto Watcher** → справа кнопка **Run workflow**.
3. В поле "seed_only" поставь `true`.
4. Нажми зелёный **Run workflow**.
5. Подожди ~30 секунд, дождись зелёной галочки.

После этого бот будет считать все текущие объявления "уже виденными", и в следующий раз пришлёт только реально новые.

## Шаг 7. Готово!

С этого момента GitHub Actions автоматически запускает проверку каждые 15 минут. Когда появится новое объявление по твоим фильтрам — придёт сообщение в Telegram.

## Запуск локально (опционально)

Если хочешь сначала проверить всё на своём компьютере:

```bash
pip install -r requirements.txt
cp config.example.yaml config.yaml   # на Windows: copy config.example.yaml config.yaml
# отредактируй config.yaml, заполни bot_token, chat_id и search_urls
python main.py
```

Для первого запуска поставь в `config.yaml`:

```yaml
seed_only: true
```

Запусти, потом поменяй на `false` — и можно гонять по расписанию.

## Запуск по расписанию на Windows (без GitHub)

Открой **Планировщик заданий** → **Создать задачу**:

- **Действие**: `python.exe` с аргументом `C:\путь\к\otomoto-watcher\main.py`
- **Рабочая папка**: `C:\путь\к\otomoto-watcher`
- **Триггер**: ежедневно, повторять каждые 15 минут

> Минус: компьютер должен быть включён. GitHub Actions — лучше.

## Частые вопросы

**Бот не присылает сообщения.**
Проверь во вкладке Actions, что прогон зелёный. Если красный — открой логи, там будет понятная ошибка (обычно неверный токен/chat_id или фильтр поиска вернул 0 результатов).

**Хочу мониторить ещё один поиск.**
Добавь URL в переменную `OTOMOTO_SEARCH_URLS` с новой строки — оба будут проверяться. Никаких других правок не нужно.

**Бот шлёт старые объявления.**
Удали все строки из `state.json` (оставь `"seen_ids": []`) и запусти workflow с `seed_only: true`. После этого старых объявлений больше не будет.

**Otomoto заблокирует за частые запросы?**
Cron на 15 минут — это всего 96 запросов в сутки на один URL поиска. Это безопасно — обычный пользователь так и листает сайт. Не ставь интервал меньше 5 минут.

**Можно вместо Telegram отправлять на email?**
Да, но это сложнее (нужно настроить SMTP, например через Gmail App Password). Если нужно — добавь модуль `email_notifier.py` с использованием стандартной `smtplib`. Пока сделано только для Telegram.
